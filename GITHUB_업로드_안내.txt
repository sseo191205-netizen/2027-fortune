2027 미래 운세 카드 - GitHub Pages 배포

1. GitHub에서 Public 저장소를 새로 만듭니다 (예: 2027-fortune).
2. 이 ZIP을 컴퓨터에서 압축 해제합니다.
3. GitHub 저장소에서 Add file > Upload files를 누르고 압축 해제한 파일 및 폴더를 올립니다.
   주의: .github 폴더도 포함해야 자동 배포됩니다. ZIP 자체를 올리면 안 됩니다.
   GitHub 웹 업로드에서 숨김 폴더가 누락되면 .github/workflows/deploy.yml을 별도로 만들어 업로드하세요.
4. Commit changes를 누릅니다.
5. Settings > Pages > Build and deployment > Source에서 GitHub Actions를 선택합니다.
6. Actions 탭에서 Deploy to GitHub Pages 작업이 성공하면 Pages에 사이트 주소가 표시됩니다.

이 프로젝트는 React/Vite 프로젝트이므로 index.html만 올려서는 안 됩니다.
